# eth-invest
Ethereum investment platform where users can invest in the ethereum cryptocurrency and get returns/profits based on selected investment plans.
# Features
- Admin panel 
  - manage users
  - manage user investments 
  - manage user withdrawals
- Login system with two-factor authentication 
- Deposit (users can make deposits either in crypto or in hard currency) 
- Invest (users can create an invesment plan based on select options) 
- Withdrawal (users can request to withdraw their investments)
